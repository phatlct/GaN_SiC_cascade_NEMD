This directory contains the processed figure files used in the manuscript.

| File | Figure in paper | Generated by |
|------|-----------------|--------------|

| `Fig1_schematic.pdf` | Fig. 1 (vector version) | `analysis/plot_fig1.py` |
| `Fig2_symptoms.png` | Fig. 2 — G and imbalance S at Δt = 1 fs | `analysis/plot_paper_figs.py fig2` |

## Summary data files

| File | Description |
|------|-------------|
| `recompute_G_corrected.csv` | G values for dt = 0.25 fs corrected runs (6 runs) |
| `recompute_G_original165.csv` | G values for all 165 dt = 1 fs original runs |
| `cutoff_vs_S.csv` | Cutoff-zone pair counts and imbalance S for 165 runs |

## Reproduction

To regenerate all figures from the raw data:

```bash
# Fig. 1 (no data needed)
python3 analysis/plot_fig1.py

# Fig. 2 (symptoms)
python3 analysis/plot_paper_figs.py fig2 \
    data/summary/recompute_G_original165.csv \
    data/summary/recompute_G_corrected.csv

# Fig. 4 (mechanism)
python3 analysis/plot_paper_figs.py fig4 \
    data/nve_drift/ \
    data/summary/cutoff_vs_S.csv

# Fig. 5 and 6
python3 analysis/plot_paper_figs.py fig5 \
    data/summary/recompute_G_original165.csv \
    data/summary/recompute_G_corrected.csv

# Fig. 7
python3 analysis/plot_paper_figs.py fig7 \
    data/summary/recompute_G_corrected.csv \
    analysis/recompute_G.py
```

See `analysis/README_analysis.md` for full usage of each script.
